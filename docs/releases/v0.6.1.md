## v0.6.1 维护更新

- 软件界面默认改为中文，包括首页、设置页、菜单和常见提示。
- 默认不再勾选鼠标滚轮方向反转。
- 未配置或无法打开 Jellyfin 服务地址时，首页只显示配置提示和“打开设置”按钮。
- 设置保存后自动关闭设置窗口，并在主窗口显示自动消失的保存提示。
- 仓库默认 README 改为中文，英文文档移至 `README.en.md`。
- 更新构建文档、需求说明和更新日志。
- 修复 GitHub Release 页面中文乱码问题；后续 Release 发布脚本改为 PowerShell 7，并从 UTF-8 Markdown 文件读取正文。

## 下载

下载 `JellyfinExternalPlayer-v0.6.1-win32-x64.zip`，解压后运行 `JellyfinExternalPlayer-v0.6.1.exe`。

## 说明

- 公开发布包不包含 `data`、`cache`、Cookies、登录态或本机设置。
- 如需保留旧版本登录状态和设置，可手动把旧包里的 `data` 目录复制到新包目录。
- 英文文档见仓库中的 `README.en.md`。
