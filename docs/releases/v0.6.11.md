## v0.6.11 维护更新

- 新增 `允许当前 Jellyfin HTTPS 地址使用不受信任证书` 设置项。
- 用于自签证书、证书域名不匹配或内网反向代理证书未被 Windows 信任的 HTTPS Jellyfin 服务。
- 证书放行只对当前配置的 Jellyfin HTTPS 主机生效，不会全局关闭 HTTPS 证书校验。
- Jellyfin API 请求改用 Electron 网络栈，页面加载和外部播放解析使用同一套证书策略。

## 下载

下载 `JellyfinExternalPlayer-v0.6.11-win32-x64.zip`，解压后运行 `JellyfinExternalPlayer-v0.6.11.exe`。

## 说明

- 公开发布包不包含 `data`、`cache`、Cookies、登录态或本机设置。
- 如需保留旧版本登录状态和设置，可手动把旧包里的 `data` 目录复制到新包目录。
