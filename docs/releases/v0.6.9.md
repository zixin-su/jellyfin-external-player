## v0.6.9 功能更新

- 新增 `播放地址来源` 三选一：`Jellyfin 流模式`、`直接路径模式`、`辅助服务模式`。
- 默认使用 `Jellyfin 流模式`，外部播放器通过 Jellyfin HTTP 流播放，适合大多数用户。
- 新增 NAS/Jellyfin 端辅助服务模式。客户端访问不到服务器本地媒体路径时，可以由辅助服务读取普通视频文件或 `.strm` 文件，并提供支持拖动进度的 HTTP Range 流。
- 发布包内附带单文件辅助服务脚本 `tools/strm-helper-server.js`，也提供 Dockerfile 和 docker-compose 示例。
- 设置页会根据当前播放来源只显示对应参数，并为每种模式提供问号说明。
- 新增 Jellyfin 会话数据定时和退出前落盘，减少客户端重启后要求重新登录的问题。
- 更新 STRM/辅助服务使用说明、构建文档和需求说明。

## 下载

下载 `JellyfinExternalPlayer-v0.6.9-win32-x64.zip`，解压后运行 `JellyfinExternalPlayer-v0.6.9.exe`。

## 辅助服务

如果需要在 NAS/Jellyfin 服务器上部署辅助服务，请复制发布包中的：

```text
tools/strm-helper-server.js
```

或者使用仓库中的 `Dockerfile.strm-helper` 和 `docker-compose.strm-helper.yml`。

详细说明见仓库中的 `docs/strm-helper.zh-CN.md`。

## 说明

- 公开发布包不包含 `data`、`cache`、Cookies、登录态或本机设置。
- 如需保留旧版本登录状态和设置，可手动把旧包里的 `data` 目录复制到新包目录。
- Release 页面默认使用中文。英文文档见仓库中的 `README.en.md`。
